<h2 align="center">Railway Maintenance Software Portal</h2>
<br/>

> A centralised web portal for uploading, validating, and managing railway track maintenance reports, replacing inconsistent email workflows and improving accuracy, accountability, and operational efficiency.

## ⚙️ Tech Stack

**Frontend**

- [Next.js](https://nextjs.org/)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [shadcn/ui](https://ui.shadcn.com/)
- [Zustand](https://zustand-demo.pmnd.rs/)
- [Axios](https://axios-http.com/)

**Backend**

- [Go](https://go.dev/)
- [chi](https://github.com/go-chi/chi)
- [sqlc](https://sqlc.dev/)
- [PostgreSQL](https://www.postgresql.org/)

**Infra**

- [Docker](https://www.docker.com/)

## 🔧 Features

- **Role-Based Dashboards**
  Operators, supervisors, machine in-charges, fleet managers, and admins each see a workflow built for their role.

- **Standardised Data Upload**
  Test point data and images uploaded in a unified, validated format.

- **Job Status Tracking**
  Supervisors review, approve, or flag submissions for revision.

- **Real-Time Notifications**
  Alerts for new submissions, reviews, and pending escalations.

- **Centralized Dashboard**
  All maintenance activity logged and organised for fast review.
